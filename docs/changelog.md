# Cambios

El registro de cambios completo, version por version, esta en
[`CHANGELOG.md`](https://github.com/jorgelsc-dev/wsbuilder/blob/main/CHANGELOG.md).
Cada version publicada tiene ademas sus notas en
[GitHub Releases](https://github.com/jorgelsc-dev/wsbuilder/releases).

Presta atencion a las secciones **Security** y **Changed**: indican correcciones
de seguridad y cambios de comportamiento que pueden requerir ajustes al
actualizar.
